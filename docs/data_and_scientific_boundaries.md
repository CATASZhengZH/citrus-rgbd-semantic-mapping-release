# Data and scientific boundaries

The full private archive contains restricted raw data, annotations, model weights, trajectories, and point clouds. They are intentionally excluded here.

Table 4 uses the corrected camera pose chain and 5,159 valid matched RGB-D observations. Table 6 uses 1,804 shared observation times and is a different controlled protocol. Figure 8 uses frozen online YOLO8 point clouds plus offline local sphere fitting. Its hypotheses do not establish fruit identity, complete reconstruction, validated diameter, fruit count, or yield accuracy.

Phase 19-25 multi-view fruit association/counting research is outside this paper and is absent from this release and its Git history.
